给 Codex 的可执行试验方案
版本：v1.0，2026-10-12
题目：表征相似度能否预测记忆状态在后续计算中的功能可互换性？

这是一份执行指令。请先读完，再实现。目标是完成一个可复现的计算实验，并报告支持结果、反例和无结论结果。不要预设 CKA 有预测力，也不要预设网络学会了群结构。当前文件是方案，尚未运行实验。

一、研究问题与最小贡献

在记忆内容完全相同、形成历史不同的情况下，两个神经群体状态看起来越相似，是否越能在保留接收方控制状态时相互替换，并继续正确更新记忆、完成行为任务？

将问题拆成三个可检验假设：
H1：正确匹配内容的记忆状态替换，比错误内容替换更能保持正确行为。
H2：CKA 能在原始任务表现、规则上下文和控制状态差异之外，预测替换造成的损害。
H3：这种预测能迁移到新的模型随机种子，以及预测模型未见过的历史配对。

H1 是干预有效性的检查；H2、H3 才是主要研究贡献。H1 成立不代表 H2 成立。“数学关系正确时更相似”也不自动意味着状态可互换。

神经科学定位：这是一个关于工作记忆内容、控制信号与后续行为之间关系的受控循环网络实验。数学任务提供精确的内容标签和反事实行为答案。它可以提出神经群体表征的可检验假设；单靠该实验不能证明真实脑区采用同样的编码或控制结构。

二、先避免两个设计陷阱

1. 单个确定性 RNN 的全部状态被替换后，后续运行等价于供体在相同输入下继续运行。因此，全状态替换本身不能证明记忆成分与接收方控制机制兼容。
2. 如果两个完整状态分别继续运行的损失是 L_A、L_B，双向全状态替换的有符号损失变化是 L_A-L_B 与 L_B-L_A，平均后会抵消。不要把这个平均值当作兼容性指标。

主实验使用两个学习得到的循环状态：候选记忆状态 m 和控制状态 c。只交换 m，保留接收方 c、时钟、未来输入和读出头。全状态替换只作为同上下文下的实现对照。

这是一种人为设置的控制结构：我们预先指定了可交换模块，并没有证明网络自发形成了一个天然独立的“记忆区”。候选记忆模块仍可能同时携带历史、规则上下文等信息，这正是可能造成不兼容的原因。

三、任务：保持并更新一个有序双射

正式任务 n=7；小规模代码调试可用 n=6。
采用 0-based 索引，当前记忆内容 p 是长度 n 的置换：
p[i] 表示项目 i 当前对应的位置。

三个真实更新：
N(p)=p
I(p)=p 的逆置换，即 I(p)[p[i]]=i
C(p)[i]=n-1-p[i]

I 是将双射反向后重新按统一索引表示，C 是对应位置的镜像。统一的数组定义才是实验真值；不要把取逆描述成实际物体移动。

引入两个规则上下文 r：
r=0：可见线索 A 表示 I，B 表示 C。
r=1：可见线索 A 表示 C，B 表示 I。
N 在两种上下文中都表示保持。

上下文只在试次开始展示。后续 A/B 线索不再直接揭示其真实更新，网络必须记住上下文。所有规则语义只用于数据生成和评价，不能写入网络权重或隐藏状态更新公式。

试次时序，单位为离散模型步：
(1) 上下文线索：3 步。
(2) 初始置换：5 步，输入为 n×n 置换矩阵展平；同一时刻展示完整映射。
(3) 空白保持：5 步。
(4) 前两条规则线索 H：每个槽位 1 步线索 + 3 步空白计算。
(5) 额外保持间隔 d：0 或 10 步。
(6) 后两条规则线索 S：同样每槽 1+3 步。
(7) 最后保持：5 步。
(8) 查询：持续 3 步，在第 3 步计算分类损失。

查询在交换时刻之后才出现，避免提前知道答案项目。
两类查询各占一半：
项目查询 i：回答最终 p[i]。
位置查询 j：回答最终 I(p)[j]。

输入包含上下文、规则、查询、刺激和粗粒度阶段标志。空白时置换输入为零，不能反复提供真值或中间答案。阶段标志只区分 CONTEXT/STIM/DELAY/RULE/QUERY，不提供中间内容。

训练有且只有最终查询的任务交叉熵；不加入中间状态监督、CKA 损失、代数一致性损失或状态交换训练。

四、主模型与预算

建议 PyTorch 实现以下单向控制结构：
c_t = GRU_control(control_input_t, c_(t-1))
m_t = GRU_memory(concat(stimulus_t, c_t, phase_t), m_(t-1))
output = MLP(concat(m_t, c_t, query_id, query_type))

默认记忆维度=128，control_dim=32，读出 MLP 隐层 64。
control_input 包括上下文、规则、阶段及查询；绝不能包含置换矩阵，也不能从 m 接收反馈。
m 接收初始置换与 c 的当前输出；刺激结束后置换输入全部归零。
两个状态在每个新试次开始都清零。输出是 n 类，不是整个置换的自回归生成。

c 在相同上下文、历史、时序与查询下必须与具体置换无关。用自动检查验证这一结构性质。

优化默认：
Adam，lr=1e-3，batch_size=128，gradient_clip=1.0，weight_decay=0。
正式每个种子最多 20,000 更新；每 1,000 更新用固定验证集评价。
保存验证准确率最高的检查点；并列时选择验证交叉熵较低者。
种子为 101、102、103、104、105、106；先导模型用 0。不得根据交换结果挑种子。

先做 n=7 的一个先导模型。若默认模型在上限内无法学会原任务，最多尝试一次预先指定的备用配置：记忆维度=256，其余不变。只按原任务验证表现选择容量，不按相似度与交换损害的相关性选择。
默认配置与备用配置都失败时，记录学习失败，停止正式运行，交付代码、诊断和失败报告。

默认总预算上限 12 GPU 小时。先导模型测量训练与完整评价吞吐、显存和预计总成本。没有合适 GPU 时完成数学测试与小规模基础运行检查，清楚标注正式实验未完成；不要把基础运行检查写成研究结果。不要自动扩大预算或无限搜索配置。

五、严格划分：先分置换轨道，再生成试次

枚举 S_7 的 5,040 个置换。对每个置换，用 I、C 反复作用，生成完整闭包轨道。整条轨道只能进入一个集合，防止训练输入经变换后成为测试输入。

已核验：
n=7 有 694 个轨道，轨道大小为 2、4 或 8。
n=6 有 115 个轨道。
实现必须独立复核这些数量。

使用固定 split_seed=20261012 打乱规范化轨道列表，按轨道数约 65%/15%/10%/10% 分成：
T：任务训练。
V：任务验证、先导模型诊断和探针超参数检查。
G：几何测量，不能用于训练任务网络。
B：行为干预，不能用于训练任务网络或选择几何指标。

保存全部轨道及成员、实际样本数量、随机种子、文件 SHA-256。比例按轨道数定义，实际置换比例允许略有偏差。

正式几何分析使用 G 中全部内容。
正式行为分析从 B 按固定轨道顺序取完整轨道，直至置换数首次达到或超过 128。为同一个种子的全部配对和对照复用相同内容集合。其余 B 内容保留给以后独立复现，不能根据当前结果选择。
G 与 B 的置换轨道必须严格不相交。

先导模型不访问正式 G/B。需要调试交换与评价速度时，将 V 临时分成两个不相交子集。先导模型的交换结果只检查代码和可测性，不用于挑选更有利于 H2 的模型、指标或数据划分。

六、序列训练与组合测试

每个试次固定 4 个槽位，每槽取 N/A/B，共 81 个线索词。
训练使用非 N 线索数不超过 3 的 65 个词。
按非 N 数 k=0、1、2、3 均匀抽样，再在该 k 的词内均匀抽样。上下文、保持间隔、查询类型与项目均衡采样。

主实验前缀历史：
H ∈ {NN, NA, AN, NB, BN, AA, BB, AB, BA}
共 9 种。

主实验后续线索：
S ∈ {NN, NA, NB}
共 3 种。

所有主实验 H+S 都在训练序列分布内，因此交换失败不能简单归因于网络没学过整个线索词。主实验同时使用 G/B 的新置换内容，所以仍须检查原网络对这些内容的行为表现。

第二阶段才测试 16 个四槽全为 A/B 的未见词。它们全部是新序列，但不全部是新净变换：训练 65 个词已覆盖 7 种不同净变换；四步测试中的 ABAB、BABA 才引入第 8 种净变换。请独立验证，不要把 16 个词都叫作未见代数操作。

如果网络不交换时就无法完成这些四步测试，相关交换结果有性能下限问题，不能用于否定状态兼容性。该扩展不决定主实验是否成功。

七、构造“相同内容、不同历史”的自然状态

将条件 a 定义为 (上下文 r, 前缀历史 H)。共 18 个条件。
对每个目标中间内容 q 和条件 a：
(1) 根据 r 将 H 中 A/B 解释为 I/C。
(2) 记前缀的净变换为 G_a。
(3) 初始置换取 p_a=G_a 的逆作用于 q。
(4) 从 p_a 自然运行至前两槽结束及额外保持间隔 d 结束。
(5) 保存 m_a(q,d)、c_a(d)；该时刻尚未呈现 S 和查询。

I、C 都是对合，但前缀逆变换必须反转操作顺序。例如先 I 再 C 的逆是先 C 再 I。不要因为两个算子各自是对合就认为它们交换。

同一 q 在全部条件下指完整、完全相同的置换，不是对某一个查询恰好给出相同答案。为每个缓存状态保存真值轨迹，并独立断言中间置换确实等于 q。

同一条件与 d 的 c 不随 q 变化；若变化，说明控制模块接收了内容或缓存存在错误。

八、主要干预与对照

对不同条件 a、b，以及同一个 q、d：
接收方原始状态为 (m_b(q,d), c_b(d))。
内容匹配替换为 (m_a(q,d), c_b(d))。
继续给接收方呈现 S 和查询；真值按接收方上下文 b 的规则语义计算。

18 个条件有 153 个无序配对：
同上下文 72 对；跨上下文 81 对。
每一对都评价 a→b、b→a 两个方向。
主科学评价优先看跨上下文 81 对；同上下文配对用于判断历史控制差异的作用。

必要对照：
A. 原始运行：不替换。
B. 假替换对照：替换为接收方自己状态的克隆，输出应逐项一致。
C. 内容匹配替换：主干预。
D. 错误内容替换：供体用 q'≠q，接收方 c、时序、S 和查询不变。
E. 同上下文全状态替换：(m_a,c_a)，应与供体在相同未来输入下的原始运行一致。

错误内容 q' 在 B 的不同轨道间做固定、无自匹配的置换；不得按行为结果选择。随机分配先于评价，保证总体分布一致。可将按记忆状态范数近邻匹配的错配作为附加对照，但不能替代随机错配。

对于 D，同时记录：
接收方原内容 q 的正确答案；
错误供体内容 q' 经接收方规则更新后的反事实答案。
部分查询可能偶然相同，要分别报告答案不同的诊断子集与所有查询。输出更接近供体反事实答案，才说明干预确实转移了内容；只有原任务准确率下降也可能是非特异破坏。

错误内容对照、假替换对照、全状态对照均不能加入预测模型拟合主标签。

九、几何指标：在 G 上测，在 B 上检验功能

对条件 a、b、保持间隔 d，构造记忆模块矩阵 M_a、M_b：
每行对应同一个 q∈G，列对应候选记忆模块的神经单元。
每个无序配对和 d 得到一组几何特征。CKA 不能被当作单个状态对的指标。

预先指定：
主指标：中心化线性 CKA。
基线 1：原生坐标中的归一化均方距离，保留均值偏移。
基线 2：中心化正交 Procrustes 残差。

每个种子保存未训练的初始权重，并在完全相同的 G、条件和时刻计算初始 CKA。它用于检查训练后几何的预测力是否超出架构与输入造成的初始相似性；初始网络的低任务准确率不用于主交换分析。

原生距离定义：
D_raw = mean_q ||m_a-m_b||² /
        [0.5×mean_q (||m_a||²+||m_b||²)+epsilon]。

Procrustes 残差：
先分别中心化并做整体弗罗贝尼乌斯范数归一化，再求最优正交变换 Q；
D_proc = ||XQ-Y||_F²。
Q 只用于测几何，绝不能用于实际状态替换。中心化范数为零的矩阵标为未定义，不能伪造为零距离或 CKA=1。

CKA 采用 float64，独立实现一个参考公式，并检查尺度不变性、同时重排行不变性及已知矩阵例子。将相似度与行为损害画散点图时，不能把每个查询当成独立 CKA 样本。

另训练一个固定岭回归内容探针：输入 m，输出当前 q 的 n×n 独热表。只用 T 缓存的平衡条件与保持间隔，alpha=1，中心化参数由 T 决定。在 G 上报告逐项目与完整置换解码准确率。
探针只用于表征可读性的诊断或协变量；不能反馈训练、修改状态、选择交换子空间或训练一个恢复行为的适配器。

十、功能指标：损害不能靠正负抵消

对每个方向、q、d、S、查询：
ell_native = -log p_native(正确答案)
ell_swap = -log p_swap(正确答案)

主连续指标：
L = mean[max(0, ell_swap-ell_native)]
对双向交换及全部预定内容、查询求平均，单位是 nat。
这是“替换造成的正向损害”，不让某些试次的改善抵消另一些试次的破坏。

同时必须报告：
R = mean[原始回答正确 且 替换后回答错误]，即交换新增错误率。
原始准确率、替换后准确率、两个方向各自的有符号平均损失变化。
错误内容替换的反事实准确率。
读出分布总变差或 JS 距离可作辅助诊断，不能代替行为准确率。

主要预测标签是每个“模型种子 × 条件无序配对 × d × S”的 L。
一个标签聚合全部 q、查询和两个方向。不要把这些共享状态的查询当成大量独立实验。
R 是行为意义的必要伴随指标，避免只有置信度变化却宣称行为改变。
若 L 大而 R 不变，应明确表述为概率损害，不能表述为明显行为失败。

十一、真正检验“预测”：留出种子和历史配对

预先指定简单岭回归，alpha=1；所有标准化、缺失值处理只在拟合折内完成。

M0：无几何的基线。
协变量包括 d、后续线索 S、是否跨上下文、原始平均交叉熵、G 上内容探针准确率、控制状态距离、两条前缀的非 N 数与最后线索是否相同。
控制距离用 c_a、c_b 的原生归一化均方距离。
上下文和线索作为固定类别变量；不得给每个条件对设置可以记住答案的独立参数。

M_CKA：M0 + CKA。此项相对 M0 的预测改进是预先指定的主要检验。
M_raw：M0 + D_raw。
M_proc：M0 + D_proc。
后两项用于判断普通坐标差异能否比抽象几何指标更有效，不根据结果重新指定主指标。

初始化敏感性检查：另报告 M_init=M0+初始 CKA，以及 M_init+训练后 CKA。只有训练后 CKA 提供额外预测信息，才可以谈训练塑造的几何信息；若初始 CKA 已解释同样效果，应收窄解释。此检查沿用相同留出规则，属于预先指定的次要分析。

6 折逐一种子留出：
每折的预测器只在另 5 个模型的行为标签上拟合。
而且拟合阶段只使用不包含混合前缀 AB/BA 的条件配对。
7 个非混合前缀×2 个上下文形成 14 个条件，共 91 个已见配对。

外层留出模型中的其余 62 对是历史配对测试：
跨上下文 32 对，作为主要测试；
同上下文 30 对，单独报告。
另外报告留出模型的已见配对预测，区分只跨种子与同时跨种子/配对的难度。

这里“未见历史配对”是预测器未见过其交换标签，不是任务网络从未经历过该前缀。任务网络确实训练过 AB/BA。不要混淆两个层次的泛化。

报告每折和总体的 MAE、RMSE，以及相对 M0 的改善。
Spearman 相关只能作补充，并在固定 d/S、上下文类别内计算；仅靠混合各种时间与上下文的相关性不支持 H2。
测试标签不能用于选择指标、层、时间点、alpha、阈值或好看的历史配对。

统计单位以模型种子为主。报告全部 6 个种子的效果；层级自助重采样以种子和行为置换轨道为块，保持块内方向、查询与条件配对的关联。6 个种子的区间只能说明有限模型集合中的不确定性，不足以支持普遍定律。不要用查询数量伪造很窄的置信区间。
至少保存每个轨道的聚合统计，以便正确重采样；不能只保存一个最终均值。

十二、通过门槛、停止条件与解释边界

实现门槛：
数学关系、轨道划分、内容匹配、缓存时间、假替换对照、全状态续跑对照全部通过，才进入正式实验。
训练标签应由置换数组操作生成，评价的独立实现可用置换矩阵转置/列翻转，避免同一个错误函数同时生成标签与验证自己。

原任务门槛：
固定验证集总准确率目标 ≥97%。
正式主实验原始行为按“上下文 × 后续线索 × d × 查询类型”报告，目标各层 ≥95%。
未达到门槛的种子也必须保留并报告，不因交换结果删除。相关结果标注为“原任务掌握不足”，不据此作强机制结论。

主实验可测性：
如果所有替换的新增错误率都 <0.5%，且配对 L 的四分位距 <0.01 nat，则按预定规则报告兼容性上限效应。
这可以说明本任务中替换普遍可行，但不能证明 CKA 有预测力。
如果几何指标几乎恒定或行为标签方差接近零，报告该预测问题在本设计中缺乏可识别性，不给无意义的相关系数。
不得为了制造损害而事后加入噪声、挑选差模型或改变内容匹配定义。

可支持的结论示例：
• CKA 在留出种子/配对上稳定改善 M0：它在本任务、架构与干预定义下具有增量预测力。
• D_raw 有效而 CKA 无效：中心化或旋转不变性可能抹去了与接收方控制状态兼容性有关的信息。
• 高 CKA 仍发生新增错误：几何相似不是该干预下功能兼容性的充分条件。
• 同上下文兼容、跨上下文失败：内容表示可能依赖控制上下文；不能只从内容可解码推断可复用。
• 全部交换都成功：任务存在广泛兼容性，但尚不能排序几何指标。
• 内容匹配与错误内容替换都严重失败：先排查干预是否造成非特异破坏，不直接解释成内容关系错误。

正式结果中的反例只能按事先定义的分位数规则选取用于展示，并同时给出完整分布。不能先看测试图再选择支持观点的案例。

十四、相关工作与原创性表述
