Independent figure A — Matched content, memory exchange, and continued computation.
Donor (D) and receiver (R) are two trials of the same fixed trained recurrent network. The left region matches the full current permutation q across different initial permutations p_D and p_R and operation-cue histories H_D and H_R. Equal task-defined content does not imply that the full hidden states are identical. In the middle region, m denotes memory state and c control state. The blue arrow copies m_D from donor state (m_D, c_D) into the receiver memory slot, replacing m_R in (m_R, c_R) while retaining c_R, to produce (m_D, c_R). No donor-control component is transplanted. The right region receives both the exchanged joint state and the subsequent receiver inputs: computation first continues through the same fixed recurrent network, then the original readout produces the answer. Retaining c_R specifies a component intervention, not guaranteed retention of the receiver's functional rule. The paired c_D and c_R may be identical or different; the drawing does not assume inequality or depict c as receiving only an initial context.
Cue-rule table (moved out of the graphic):
Context 0: A = inversion; B = complementation.
Context 1: A = complementation; B = inversion.
N denotes identity/no operation in either context. Complementation replaces each position label j by 8-j.
Mathematically checked example, shown only here: in context 0, p_D = [3,1,5,2,7,6,4] with H_D = AN undergoes inversion then identity; in context 1, p_R = [6,4,7,1,5,2,3] with H_R = NA undergoes identity then complementation. Both yield q = [2,4,1,7,3,6,5].

Independent figure B — Context dependence of exchange-induced errors.
Content-matched memory exchanges introduce new errors on 1.69697560% of all within-context queries and 53.39794999% of all cross-context queries (equal-weight means over the six formal networks, seeds 101–106). A new error is a receiver answer that was correct in the native trial and wrong after exchange; the denominator is all evaluated queries in the corresponding context group, including native-incorrect queries. Each point is one independently trained network; short horizontal lines indicate equal-weight means. Fixed horizontal offsets separate the six circular points and do not alter their values. Blue denotes within-context exchange and orange cross-context exchange. B1 contains 134 permutations in 19 complete permutation orbits. All prespecified condition pairs, both exchange directions, delays d = 0 and 10, suffixes S = NN, NA and NB, and seven item-to-position plus seven position-to-item queries are retained with the original condition weights. No correctness-based post-exchange selection, error bars or new uncertainty estimates are used. Query records are dependent observations within networks, not additional independently trained networks.

Independent figure C — Cue translation has opposite effects after exchange and in native trials.
On held-out permutations, cross-context exchange accuracy changes from 42.06742012% with original cues to 97.85815177% with translated cues, whereas native, unexchanged accuracy changes from 97.85817207% to 42.06742012%. Every accuracy is evaluated against the original receiver task target. Translation swaps A and B and preserves N. Fine paired lines and circular endpoints show the six networks in each group; thick lines show their equal-weight means. The same six networks contribute to both groups, for twelve paired traces in total; the groups do not represent twelve separately trained networks. Horizontal offsets separate overlapping endpoints and preserve each network's pairing. Orange solid means denote cross-context exchange; purple dashed means denote native/no exchange. The no-exchange control uses actual unpatched native trials, never same-context exchange. The dataset identifier is B_reserved: 362 permutations in 51 complete orbits, held out from the earlier B1 exploration. This figure reuses saved results and is not a new independent confirmation. All prespecified suffixes, including NN, both delays d = 0 and 10, both query types, and all receiver conditions/directions retain the original weights. The translation leaves NN unchanged.
