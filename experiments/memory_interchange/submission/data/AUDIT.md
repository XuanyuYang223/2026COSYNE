The selected rows are exported as donor_text_support.csv. The narrower fixed-model conditional interval [-0.0740167703, 0.0735117724] nat is descriptive, excludes model-fitting/training uncertainty, and is not substituted for the original interval. No predictors are refit here. No general claim that CKA is ineffective is made. Seed 106, weak native strata, and the original strict CPU float32 tolerance failure remain included; registered GPU checks passed and compared argmax outputs were unchanged.
