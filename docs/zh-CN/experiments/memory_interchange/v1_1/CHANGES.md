# v1.1 修改记录

v1.0 源码、报告、配置、检查点和数据保留原位；101 个原产物同时打包归档并记录 SHA-256。v1.1 只新增此包、`runs/v1_1/` 和 `results/v1_1/`，不修改原划分或正式 B 的 134 个内容。

- 新增实际批次整理真值核验器：只从刺激、可见上下文/规则和最终查询恢复答案，独立检查标签、输入重复、有效步、查询时长及填充。
- 补齐旧最佳/最新检查点在固定 T、平衡 V 与未改动原 V 上的行为、刺激移除/打乱响应。
- 新增真实旧训练采样器的 128 试次路径检查；即时执行携带状态节点 retain_grad，和实际融合实现前向计算的 logit、刺激导数及参数导数比较。短试次增加 CPU float64 自动微分与有限差分抽查。没有发现旧训练前向计算的实现错误。
- 新增三个时序和七阶段课程；仅最终任务 CE，结构固定 128/32/64。候选 A 使用默认初始化；唯一 B 只将两个 GRU 的有效更新偏置初始设为 +3，所有参数仍可训练。
- 固定阶段 T/V 评价集合与小型拟合集合在任何新训练开始前生成保存。原固定 V 8,192 试次逐字段复用；新增平衡 V 是单独诊断集合，不能替换阶段 7 的原 V。
- 从头训练单独保存，从不向课程迁移权重。阶段晋级恢复同一晋级检查点的权重、Adam 状态和全部 RNG；修正中断恢复在已达晋级点/失败上限处继续训练的潜在风险。此恢复修正未改变本轮连续运行的优化轨迹。
- 新增状态敏感性、门分布、分层计数、每阶段诊断和计算成本；审计增强只增加观察/一致性检查，不修改优化器、损失、数据分布或本轮已运行的模型参数。
- 保持原始 97% 总体与 95% 因素层门槛；两个连续 500 更新评价通过后晋级。适用算子因素按移除 N 后的真实 I/C 操作序列定义，和上下文、d、查询类型、非 N 数分别报告，未使用极细交叉格作课程门槛。
- 全过程禁止访问正式 G/B 的模型输入、几何—损害相关与科学预测器。若未来本版本先导模型达到任务就绪（TASK_READY），冻结配置/源码后才可能另行开展正式实验；本轮不自动运行。

官方 [GRU 文档](https://docs.pytorch.org/docs/2.14/generated/torch.nn.GRU.html) 的 r/z/n 排列和保留系数方程已与本机 torch 2.11.0+cu128 的源码核对。未升级旧实验的 PyTorch。梯度模式审查依据 [自动微分机制](https://docs.pytorch.org/docs/2.14/notes/autograd.html)，并用本机实际前向计算/导数验证。
