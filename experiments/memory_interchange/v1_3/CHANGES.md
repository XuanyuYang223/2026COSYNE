# v1.3 登记与实现说明

seed0 锁定阶段 7 的 V 总准确率 best（49,500），不续训；旧 v1.2 BLOCKED 和 latest 分层原样保留。V 沿用旧几何前 52 轨道及行为后半 6 轨道，仅作探索。

阶段 1–6 的正式课程与细因素门槛不变；阶段 7 晋级只用总准确率≥97%，k/context/d/query_type各层≥95%，连续两次。全部真实操作细层继续记录。六种子101–106新初始化，失败者保留，上限及 Adam 等参数不变。

主标签仍为 L_all；新增固定自然输出定义的 rec/both/three mask，匹配与错内容共用。R_all 分母为全查询，R_rec 分母为原答正确查询。保存修复率、方向、当前/初始输入反事实及映射重合。T 上同样本、同中心化、alpha=1 的两个探针分别读出当前/初始内容。

预测保持 LOSO 和历史配对留出，主基线 M0_v13=M0_old+D_input，主模型再加 CKA。D_input 仅在 G 的初始输入 one-hot 矩阵计算。保留旧 M0+CKA、原生距离、Procrustes、初始 CKA；rec/both 是敏感性分析，质量档仅用于报告。

CPU float32 的额外严格 logits 对照在训练后权重上出现近零 logit 的数值差。记录所有失败条件、最大差、预测改变数；同一权重精确转 float64 后沿用原 2e-7/2e-6 容差复核。实际 GPU float32 干预依旧沿用注册 logp 1e-5/1e-5，sham 必须逐项相同。没有放宽阈值、修改权重或按交换效果选择内容。

正式 G/B 打开前冻结本版源码、配置、内容、mask/质量定义、模型与预测规则。V 结果不决定是否正式运行。累计 12 GPU 小时沿用此前精确 1080.078962639178 秒。
