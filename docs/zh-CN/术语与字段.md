# 术语、数据字段与统计口径对照

本页解释原文、图表和数据文件中的英文标记。中文阅读版只翻译显示文字；实际文件名、程序接口、JSON/CSV 列名和数组中的取值保持原样。

## 状态与处理

| 原标记 | 中文含义 |
| --- | --- |
| `m` / `memory` | 人为指定的记忆状态组件；可能携带内容、上下文、历史或初始输入 |
| `c` / `control` | 人为指定的控制状态组件；保留该组件不能自动证明保留了接收方实际使用的规则 |
| `donor` / `a` | 供体：提供被交换记忆状态的条件 |
| `receiver` / `recipient` / `b` | 接收方：保留其控制组件的条件 |
| `native` | 原生状态续跑的输出 |
| `natural` | 不间断运行的自然输出；与从缓存状态续跑的 `native` 字段分开 |
| `patch` / `matched` | 在内容相同的条件下，以供体记忆替换接收方记忆 |
| `wrong` | 使用错误内容的供体记忆进行替换 |
| `sham` | 假替换对照 |
| `full` | 全状态交换对照；解释时仍须检查后续实际输入相同 |
| `original` | 一致性复核中指未翻译的后续线索；课程说明中也可指原始时序 |
| `translated` | 未来线索中 A/B 对换、N 不变的处理 |
| `same` / `cross` | 上下文分层中分别为同上下文、跨上下文；历史分层中的 `same` 为同历史 |
| `different` | 历史不同 |

## 内容、线索与查询

| 原标记 | 中文含义 |
| --- | --- |
| `r` / `context` | 规则上下文，取 0 或 1 |
| `H` / `history` | 交换前的可见线索历史 |
| `S` / `suffix` | 原接收方字面后缀，分层仍按此标记 |
| `effective_suffix` | 实际送入网络的后缀；翻译后的 NA 使用 NB，翻译后的 NB 使用 NA |
| `q` / `content_id` | 共享的当前完整任务内容及其标识 |
| `p_a` | 供体的初始置换，满足 `p_a=G_a^{-1}(q)` |
| `d` / `delay` | 保持间隔，取 0 或 10 |
| `I` / `inverse` | 逆置换操作 |
| `C` / `complement` | 位置镜像操作 |
| `N` / `KEEP` | 保持不变 |
| `true_operation_sequence` | 移除 N 后的真实操作序列，例如 IC、CI |
| `non_N` | 非 N 操作的数量 |
| `query_type=0` / `item` | 项目查询：给定项目，预测其位置 |
| `query_type=1` / `position` | 位置查询：给定位置，预测其项目 |
| `query_item` / `query_id` | 被查询的项目或位置索引 |
| `orbit_id` / `orbit` | I/C 闭包下的完整轨道及其标识；轨道是块重采样单位 |

上下文 0 中 A/B 分别表示 I/C，上下文 1 中 A/B 分别表示 C/I。可见词 AB 不能脱离上下文直接当作真实操作 IC。条件编号先列上下文 0 的九个历史，再列上下文 1 的同一历史顺序：`NN,NA,AN,NB,BN,AA,BB,AB,BA`。

## 样本口径与数据集合

| 原标记 | 中文含义 |
| --- | --- |
| `all` | 全体可用查询，主描述口径 |
| `rec` | 接收方原生输出对原 S 答对的查询子集 |
| `both` | 接收方与供体分别对同一可见原 S、按各自规则答对的子集 |
| `three` | 在 `both` 基础上，另要求错误内容供体在自身规则下答对；三方答案无需相同 |
| `E_sem` | 接收方原 S 正确，且供体能正确执行同一语义运算的子集；跨上下文供体用翻译 S，同上下文用原 S |
| `mask` | 在替换前按原生输出冻结的样本选择掩码 |
| `T` / `V` / `G` / `B` | 分别用于训练、任务验证、几何评价、干预行为评价的原轨道划分 |
| `B1` | 原 B 中首次选定的 134 个内容、19 条完整轨道 |
| `B_reserved` | 原 B 减 B1 的其余 362 个内容、51 条完整轨道；最新一致性复核时也已用于此前分析 |

不同版本的掩码须依各自冻结定义解释；不能通过翻译或统一名称合并样本。一个供体原生输出可以与多个接收方配对，扩展后的查询计数不等于独立原生错误样本数。

## 概率、误差与统计量

| 原标记 | 中文含义 |
| --- | --- |
| `logp` | 自然对数概率；一致性复核转为 float64 概率后检查有限值与归一化 |
| `logit` | 归一化前的输出分数；共同平移不改变概率 |
| `argmax` | 最大分数或概率对应类别；并列时采用最小类别索引 |
| `CE` | 交叉熵 |
| `nat` | 采用自然对数的量纲单位 |
| `TV` | 总变差距离，即类别概率绝对差之和的一半 |
| `max_abs_probability_difference` | 单次查询各类别概率的最大绝对差 |
| `answer_agreement_equal_cells` | 各非空方向×间隔/后缀×查询类型单元率等权，再在六模型间等权 |
| `answer_agreement_pooled` | 实际相同答案总数除以可配对查询总数 |
| `q95` / `q99` | 概率差分布的第 95 / 99 百分位数 |
| `item7` / `position7` | 分别为七个项目查询、七个位置查询的答案全部一致 |
| `MAE` / `RMSE` | 平均绝对误差 / 均方根误差 |
| `CKA` | 中心化核对齐，表征几何相似度 |
| `D_raw` | 原生坐标中的归一化状态距离 |
| `D_mean` / `D_center` | 原生距离的均值差与中心化差分解 |
| `Procrustes` | 正交普氏对齐比较 |
| `ridge` / `alpha` | 岭回归及其正则化系数 |
| `LOSO` / `fold` | 每次留出一个模型种子的预测评价 / 对应留出折 |
| `bootstrap` | 自助重采样；最新一致性区间固定六模型、共同重采样完整轨道 |
| `refit bootstrap` | 每次重采样后重新拟合预测器；与固定预测的条件经验区间分开 |
| `pp` | 百分点，表示两个百分率之差 |

答案一致、概率容差内接近、逐元素精确相等分别报告。完整十四查询向量相同也不等于预测是合法双射或完整置换正确。供体错误的判断须使用供体在实际后缀下的自身真值。

## 文件、训练记录与状态

| 原标记 | 中文含义 |
| --- | --- |
| `seed` | 模型初始化或重采样的随机种子，具体含义依字段位置确定 |
| `pilot` | 正式多种子实验前的先导模型 |
| `initial` / `best` / `latest` / `advance` | 初始 / 最佳 / 最新 / 晋级检查点 |
| `selected_stage7.pt` | 正式模型阶段七选定并冻结的检查点 |
| `RNG` | 随机数生成器状态 |
| `manifest` / `SHA-256` | 成员或产物清单 / 完整性散列 |
| `float32` / `float64` | 单精度 / 双精度浮点格式 |
| `TASK_READY` | 先导模型已通过对应版本的完整任务要求，科学分析尚未完成 |
| `COMPLETED` | 对应版本预定工作完成；仍须查看实际行为门槛和数值检查状态 |
| `EXPLORATORY` | 探索性结果或正式样本、检查不足 |
| `PARTIAL` | 仅完成部分工作，存在列明的缺失项 |
| `BLOCKED` | 达到对应版本预算或实现停止条件而受阻 |

原数值注记始终保留：登记的 GPU 对照通过；CPU float32 原严格 logit 容差未通过；相同系数的 float64 一致，原比较的 argmax 不变。最新复核使用的概率容差不替代该检查。
